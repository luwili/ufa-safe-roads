# Безопасная Уфа: Умные дороги и скидка на ОСАГО

Проект состоит из двух связанных веб-приложений для г. Уфы (Республика Башкортостан):

1. **Главная платформа (`index.html`)** - подробная карта камер (синхронизация с OpenStreetMap Overpass API), 12 зон риска и пилотных участков «Умной дороги», графическая аналитика по районам и нарушениям, визуализации технологий из аналитического доклада и калькулятор скидки на ОСАГО.
2. **Прототип «ОСАГО+» (`osago/index.html`)** - отдельный демонстрационный интерфейс программы скидки без балльной системы (`0 нарушений -> 12%`, `1 -> 9%`, `2 -> 6%`, `3 -> 3%`, `4+ -> 0%`). Сценарий ЕСИА, примеры постановлений и макет сертификата работают локально: подключений к Госуслугам, ГИБДД или страховым компаниям нет.
